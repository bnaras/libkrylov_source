----------------------------------------------------------------------
Solver Libraries are installed in:
   $(libkrylov)/src/<type>_<precision>_lib
Alongside utility programs   

Unit testing programs, are installed in:
   $(libkrylov)/src/<type>_<precision>_test

Modules are backed up in:
   $(libkrylov)/src/<type>_<precision>_mods
if the main directory is cleaned.

Linking Fortran files requires linking
both a library/object file and module files used.
ax_f90_library_setup of autoconf-archives is a convenient
macro to use or reference.

Flags to include for linking are
-I$(libkrylov)/src/ \
-L$(libkrylov)/src/<type>_<precision>_lib/libkrylov_<type>_<precision>.a \
-Wl,-rpath -Wl,$(libkrylov)/src/<type>_<precision>_lib

with the first line replaced by 
-I$(libkrylov)/src/<type>_<precision>_mods/ \
if the backup is to be used.
----------------------------------------------------------------------
